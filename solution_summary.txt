ГОТОВ К РЕАЛИЗАЦИИ

Реализовано инженерное решение для безопасного переключения между Google Calendar календарями в XO_OS с переносом только событий уроков XO_OS.

Ключевые компоненты решения:
1. Таблица блокировок `calendar_switch_locks` для предотвращения гонок при быстрых переключениях
2. Фоновая задача `switch_calendar_for_user` в GoogleCalendarSyncService для обработки перемещения событий
3. Транзакционная обработка уроков по одной для обеспечения согласованности при частичных сбоях
4. Обновление маршрута выбора календаря для определения необходимости переключения vs начальной синхронизации

Решение обеспечивает:
- Перемещение только событий уроков XO_OS между календарями
- Сохранение связей между уроками и событиями
- Нет вмешательства в личные события
- Устойчивость к частичным сбоям
- Предотвращение гонок при быстрых переключениях
- Возможность возобновления после прерывания
- Минимальные изменения существующей архитектуры

Все критические сценарии обработаны корректно. Оставшиеся риски (возможные дубликаты при определенных сбоях, коллизии event ID) документированы и считаются приемлемыми для минимального изменении решения.
