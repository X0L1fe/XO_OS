# XO_OS / MAISync — описание интерфейса

## 1. Общая концепция

**XO_OS** — это персональная операционная система пользователя, построенная вокруг идеи превращения реальной жизни в управляемую игровую систему.

MAISync является инфраструктурным ядром, которое объединяет:

* расписание МАИ из ICS;
* Google Calendar;
* задачи и проекты;
* Obsidian;
* статистику;
* игровую систему прогресса;
* локального AI-агента.

Главная задача интерфейса — не показать пользователю как работает синхронизация, а ответить на три вопроса:

> **Что мне делать сейчас?**
> **Насколько хорошо я справляюсь?**
> **Как меняется мой прогресс?**

Технические детали синхронизации должны оставаться вторичными.

---

# 2. Визуальный стиль

Стиль:

**dark / minimal / futuristic / productivity RPG**

Основная палитра:

* почти чёрный фон;
* тёмно-синие панели;
* белый основной текст;
* холодный синий как основной accent;
* фиолетовый для вторичных элементов;
* зелёный для успешных действий;
* жёлтый для предупреждений/достижений;
* красный только для негативных событий.

Интерфейс должен выглядеть как **панель управления персонажем**, но без ощущения дешёвого игрового UI.

Важно сохранить минимализм: экран не должен превращаться в стену из карточек.

---

# 6. Характеристики персонажа

Рядом находятся четыре основных параметра:

### Focus

```text
78 / 100
```

Отражает соблюдение запланированного времени.

### Energy

```text
65 / 100
```

Отражает состояние нагрузки и восстановления.

### Discipline

```text
82 / 100
```

Отражает стабильность выполнения планов.

### Productivity

```text
71 / 100
```

Обобщённый показатель эффективности.

Эти параметры **не должны вводиться вручную** — они рассчитываются системой на основе данных.

---

# 7. XP и Level

XP является главным игровым ресурсом.

Источники XP:

```text
Выполненная задача          +40 XP
Учебный блок                +60 XP
Сложная задача              +80 XP
Закрытие milestone         +150 XP
Успешный день               +100 XP
Streak bonus                +XP
```

Текущий уровень определяется накопленным XP. Текущая документация уже задаёт базовую систему XP/level/streak, поэтому UI должен визуализировать её, а не создавать параллельную механику. 

---

# 8. Debuff System

Негативные события отображаются как игровые состояния.

Например:

```text
Пропущена задача
-20 XP
```

```text
Задача перенесена 3 раза
Discipline -5
```

```text
Нарушен streak
Streak reset
```

```text
Перегрузка
Energy -10
```

При этом интерфейс не должен выглядеть осуждающим.

Это не система наказаний, а визуализация поведения пользователя.

---

# 9. Блок «Сейчас»

Это **главный рабочий блок интерфейса**.

Он показывает действие, которое пользователь должен выполнить прямо сейчас.

Например:

```text
СЕЙЧАС

РАЗРАБОТКА

Реализовать Google Calendar adapter

Добавить поддержку создания,
изменения и удаления событий.

1 ч 30 мин
Высокий приоритет
+80 XP

                 [ НАЧАТЬ ]
```

Именно этот блок должен визуально привлекать внимание больше всего.

# 15. План против факта

Это особенно важная статистика для будущей Life OS.

```text

Учёба
42 ч                    39 ч

Проекты

8 ч                      6 ч
```


# 22. Obsidian

Obsidian является **knowledge layer** системы.

MAISync уже предусматривает экспорт занятий в Markdown и работу с vault. 

В интерфейсе это должно выглядеть максимально просто:

```text
Obsidian
● Connected

Vault:
D:\Obsidian\LifeOS

Последняя синхронизация:
Сегодня, 12:42
```

Не нужно превращать Obsidian integration в отдельный огромный экран.

---

# 23. Google Calendar

Google Calendar является **time layer**.

Интерфейс:

```text
Google Calendar
● Активен

MAISync → Google Calendar
```

Синхронизация должна работать автоматически.

Причём UI показывает не технические запросы API, а человеческую информацию:

```text
Последняя синхронизация:
14:32

Создано:
1

Обновлено:
2

Перенесено:
1

Удалено:
0
```

# 26. Самое важное правило дизайна

**Не пытаться показать всё на главной.**

Главная должна быть:

```text
PLAYER
    ↓
СЕЙЧАС
    ↓
СЛЕДУЮЩЕЕ
    ↓
ПРОГРЕСС
    ↓
СТАТИСТИКА
```

А:

```text
Google Calendar sync
ICS
database
Obsidian
API
logs
```

уходят на отдельные страницы.

Так интерфейс останется таким же чистым, как на последнем референсе, но при этом сохранит то, ради чего вообще создаётся XO_OS: **игровой прогресс + реальные планы + аналитика + управление действиями**.
